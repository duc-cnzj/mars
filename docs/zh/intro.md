# 💡 简介

**Mars** 是一个帮你部署、运行应用的平台。你写好代码推到 Git，Mars 就能把它变成 Kubernetes 上跑起来的应用——连 HTTPS 域名都配好——大约 30 秒。

> **You write the code, we ship it live. 30 秒内部署一个生产级应用。**

## 给谁用？

- **开发者**：不想把时间耗在 K8s 和 Helm 细节上，只想把东西发布出去
- **运维**：管理大量应用和环境，需要一个统一的发布入口
- **产品/运营**：需要快速搭一套联调或演示环境——不懂代码也能用

## 你能用它做什么？

| 你可以… | 怎么做 |
|---|---|
| 部署一个应用 | 关联 Git 仓库，点「部署」——完成 |
| 给它配域名 | Mars 自动配置地址和 HTTPS 证书 |
| 在浏览器里排障 | 打开容器终端、看实时日志、拷文件 |
| 看资源占用 | 看每个容器的 CPU / 内存，还有 Pod 排行 |
| 发新版本 | 改一下镜像 tag 再部署——滚动升级 |
| 出问题回滚 | 一键回到任意历史版本 |
| 管一个团队 | 命名空间分公开/私有，角色有管理员、创建者、成员 |
| 满足合规 | 每次部署、每个操作都有记录，终端会话可回放 |
| 单点登录 | 对接公司 OIDC，不用记密码 |

## 用大白话讲它怎么工作

- 你的应用由一个 **Helm chart** 描述——这是一种标准的、可移植的应用定义方式。
- Mars 里存着你的 **命名空间**（一组应用的集合）和 **项目**（你的 Git 仓库 + chart 配置）。
- 点「部署」后，Mars 按你的 chart 在 **Kubernetes** 集群里把应用跑起来。

你不需要精通 Kubernetes 和 Helm——界面帮你搞定了。
