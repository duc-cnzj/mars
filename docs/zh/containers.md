# 🐳 容器与日志

Mars 让你在浏览器里直接操作运行中的容器——不需要 `kubectl`。

## 打开终端

点某个容器，选 **终端**。会在那个容器里打开一个 shell，方便实时排障——看配置文件、跑命令、到处看看。

- **一次性命令** 选项：执行单条命令并显示输出。
- 想回看刚才的操作？终端会话会被**录制**，详见 [审计与历史](./audit.md)。

## 看实时日志

选一个容器，打开它的 **日志**。输出实时滚动，看应用启动过程、追踪报错很方便。

## 拷贝文件

在你的电脑和容器之间传文件：

- **拷进容器** — 把一个文件（比如配置文件、热修补丁）上传到容器里的某个路径。
- **从容器拷出** — 把容器里的文件下载到电脑。

拷贝日志、导数据文件、不重新构建就能塞个快速修复，都很实用。

## 看资源占用

| 视图 | 你能看到 |
|---|---|
| 单容器 | 该容器的 CPU 和内存占用 |
| 项目 / 命名空间 | 整个项目或空间的 CPU、内存 |
| Pod 排行 | 哪些 Pod 最吃资源——排查「谁在狂占」很方便 |

## 权限

在某个命名空间里开终端、看日志，需要**该命名空间的访问权**——公开空间任何登录用户都可以；私有空间要成员身份。见 [权限管理](./access-control.md)。
