# ⚙️ Configuration

Mars reads YAML configuration via `-c, --config`; it defaults to `config.yaml` in the current directory (generated by `./bin/app init`; see the full example in [config_example.yaml](https://github.com/duc-cnzj/mars/blob/master/config_example.yaml)).

## CLI

The binary's root command is `app`:

| Command | Description |
|---|---|
| `app serve` | Start all services (api / metrics / cron / profile) |
| `app inspect` | Inspect runtime info: `all` / `tags` / `cronjobs` / `events` / `plugins` / `config` |
| `app init` | Generate a default `config.yaml` |

Common `app serve` flags:

```bash
app serve -c config.yaml \
  --app_port 4000 \
  --grpc_port 50000 \
  --metrics_port 9091 \
  --kubeconfig ~/.kube/config \
  --exclude_server metrics,cron,profile
```

> Config can also be overridden via environment variables with the `MARS` prefix.

## Reference Table

Aligned with `config_example.yaml`; values shown are the defaults.

### Server & General

| Key | Default | Description |
|---|---|---|
| `app_port` | `4000` | HTTP/JSON (gateway) port |
| `grpc_port` | `50000` | gRPC port |
| `metrics_port` | `9090` | metrics port |
| `debug` | `false` | debug mode |
| `exclude_server` | `""` | server tags to exclude, e.g. `cron,api,metrics` |
| `log_channel` | `zap` | log channel: `logrus` / `zap` |
| `git_server_cached` | `true` | cache git requests (git is slow, on by default) |
| `db_auto_migrate` | `false` | auto-migrate the database schema |
| `cache_driver` | `memory` | cache driver: `memory` / `db` |
| `external_ip` | `127.0.0.1` | externally reachable IP of the cluster |
| `ns_prefix` | `devops-` | prefix added to all namespaces managed by mars |
| `install_timeout` | `90s` | Helm install timeout |
| `tracing_endpoint` | `""` | OTLP tracing endpoint (e.g. Jaeger 4317) |
| `admin_password` | `123456` | admin password |
| `private_key` | `""` | RSA private key (signs access tokens) |

### Storage

| Key | Default | Description |
|---|---|---|
| `db_driver` | `sqlite` | storage driver: `sqlite` / `mysql` |
| `db_database` | `/tmp/mars-sqlite.db` | absolute db path for sqlite; database name for mysql |
| `db_host` / `db_port` / `db_username` / `db_password` | `127.0.0.1` / `13306` / `root` / `""` | required for mysql, ignored for sqlite |
| `db_slow_log_enabled` | `true` | enable slow query log |
| `db_slow_log_threshold` | `200ms` | slow query threshold: `ns` / `us` / `ms` / `s` / `m` / `h` |
| `db_debug` | `false` | enable ent debug mode (prints SQL) |

### Files & S3

| Key | Default | Description |
|---|---|---|
| `upload_dir` | `/tmp/mars-uploads` | directory for uploaded files |
| `upload_max_size` | `50m` | max upload size (supports `MB` / `Gi` / `m` / `g`) |
| `s3_enabled` | `false` | upload files to S3 |
| `s3_endpoint` | `""` | MinIO / S3 endpoint |
| `s3_access_key_id` / `s3_secret_access_key` | `minioadmin` | S3 credentials |
| `s3_use_ssl` | `false` | use SSL |
| `s3_bucket` | `mars` | S3 bucket name |

### Private Image Registry

```yaml
imagepullsecrets:
  - username: "jack"
    password: "12345"
    email: "jack@example.com"
    # server defaults to "https://index.docker.io/v1/"
  - username: "john"
    password: "12345"
    email: "john@example.com"
    server: "registry.cn-hangzhou.aliyuncs.com"
```
